# 庭录接入项目工具

目标是在已有云网站中提供与 SimCourt 并列的庭录入口，转写和任务文件仍由校园服务器处理。访问链路为浏览器 HTTPS → 云平台鉴权及代理 → 受限加密隧道 → 校内庭录。云端承担传输流量，不复制模型权重或运行 Whisper；上传过程中视频数据会经过云端，不能承诺“视频从不经过云服务器”。

## 现场检查与当前阶段

用户已回传两台服务器检查：云平台 0.11.0、平台会话和既有工具代理运行，本站上传上限 256 KiB；校内庭录 0.2.0 运行、匿名任务访问 401。额外工具监听的用途已从已有私有部署资料确认属于 SimCourt，不复用该端口。初版检查器漏列现有工具配置目录，现已补齐允许目录和失败状态报告，不要求重复此前检查。实际配置、路径和结果只保存在忽略目录。

`tools/integration_preflight.py` 是 Python 3.10+ 标准库只读检查器。它不导入运行中的应用、不读取凭证专用文件、环境文件、数据库或任务内容，不发送认证信息，不生成文本、不安装软件、不启停服务。Nginx 配置只在内存读取并提取白名单字段，不回传原文，也不运行可能打开日志文件的 `nginx -t/-T`。

在开发电脑生成两份离线 Bash 块，真实站点名称与输出只放忽略目录：

```powershell
python tools/build_integration_preflight.py --site models.example.test
```

- `cloud-integration-check.commands.sh`：在已有阿里云 Bash 终端运行。汇总活跃平台的版本/源码摘要、会话代理开关、工具登记、本站 Nginx 路径和上传限制、监听端口、匿名健康状态、现有专用 SSH 账号的本地来源配置样本。
- `campus-integration-check.commands.sh`：在已有校园服务器 Bash 终端运行。汇总庭录服务和源码摘要、匿名登录入口、未登录任务拒绝、隧道客户端状态及监听端口。

每份块使用现有 sudo 权限，先核对内置源码长度、SHA256，再在内存执行；无下载步骤。遇到与角色不符或未运行的目标服务会提前停止。独立检查失败时保留其他检查结果，不输出可能携带秘密的异常正文。末尾 `INSPECTED` 只表示检查执行完毕，须阅读 HTTP 状态和具体结果，不能当作公网接入或隧道健康通过。`NEEDS_REVIEW` 表示需要根据输出定位，无需重跑安装。

SSH `-T -C` 仅采样本地来源的配置，实际出口来源的 Match 规则、authorized_keys 限制及当前连接仍须另行核实。监听存在也不能单独证明隧道可用。输出包含私有部署信息，只保存在 `.state/`，不进入公开仓库。

## 适配范围及验收

服务器现有代理针对单个 SimCourt 工具，按完整请求体签名，且有 256 KiB 请求和 4 MiB 响应上限。平台源码 0.11.1 现已支持多个独立配置和庭录专用代理：每块最多 4 MiB，逐块使用相同的 v1 Ed25519 断言绑定目标、请求体摘要、身份、到期时间和一次性 nonce；PATCH 仍需签名和平台 CSRF。原工具和平台其他入口仍使用原上限，不能绕过校验上传整段视频。

庭录源码 0.3.0 验证签名后映射到 `platform:usr_…` 归属；原校园 Cookie 用户保持原 ID。分块初始化以用户和请求 ID 幂等，重复同一块须字节摘要一致；合并前落盘完成状态标记，成功返回稳定任务 ID，未知合并不自动重复提交。每人两个、全局八个未完成上传，保留磁盘空间用于分块和合并副本。页面内可检查已接收块后继续，也可显式清理本人仍在接收的上传；刷新后的自动断点恢复尚未实现。

签名和一次性 nonce 在开始接收时验证，块到齐后仍须逐字节计算并比较摘要，之后才进入应用。已过期的请求头提前拒绝；传输期间经过到期时间不重新接纳第二个请求。TLS 转发进程直接转发有界数据流，避免先在该进程缓存整块而推迟鉴权。约束参考 [RFC 9421 安全考虑](https://www.rfc-editor.org/rfc/rfc9421.html#section-7) 和 [RFC 9530 摘要安全考虑](https://www.rfc-editor.org/rfc/rfc9530.html#section-6)，消息仍使用现有应用层 v1 格式。

| 平台用户接口 | 请求与结果 |
| --- | --- |
| `POST /api/uploads` | JSON 文件名、总字节数、Options 和 32 位请求 ID；返回稳定上传 ID、块大小和已接收列表 |
| `POST /api/uploads/{id}/parts/{n}` | 原始二进制块，长度必须匹配；同一块重复提交须摘要相同 |
| `GET /api/uploads`、`GET /api/uploads/{id}` | 仅返回本人的未完成上传或指定上传状态 |
| `POST /api/uploads/{id}/finish` | 合并、实际媒体检查、记录归属、入队；成功重复调用返回同一任务，未知完成状态返回 409 |
| `POST /api/uploads/{id}/abort` | 显式清理本人接收中或已失败的分块，不删除已发布任务，不中止仍在合并的请求 |

这些接口要求由已批准的平台管理员或普通成员发出的逐次签名；校园 Cookie 不能替代平台签名。错误分别为 401 身份失败、403 登录方式或 CSRF 不符、404 无归属、409 状态/内容冲突、413 大小限制、429 数量限制、507 磁盘不足。媒体、编辑和导出继续使用原有任务接口与归属检查。

下载与单段 Range 经流式转发，云端只在内存暂存有界分块，不缓存整段视频。校内 TLS 转发进程不创建 Runner 或加载模型，只连接既有庭录应用，由后者统一拥有队列和文件。上传合并仍会产生校内磁盘副本；不是端到端加密到用户电脑之外不可见的方案。

平台会话身份必须由服务端验证并映射为稳定且带命名空间的庭录用户；浏览器传入的用户 ID 或任意身份头不能成为信任依据。平台账号退出、过期、禁用和跨账号访问应及时拒绝，任务、媒体、抽帧、原文编辑与导出均检查归属。旧校园凭证任务不得自动转给同名平台账户，迁移需明确映射。

下一步 `tools/build_platform_bundle.py` 生成不含模型、wheel、字体或私钥的增量准备包；字体从原版本按 SHA256 复用。`tools/upload_platform_bundle.ps1` 沿用普通 SSH 校验续传，输出完整校内 Bash 准备块。服务器准备器核对原版本源码及服务归属，只在私有 root 准备目录保存候选源文件并生成 TLS 材料；重复完整准备复用同一证书，发现源文件变化、半完成或篡改则保留材料并拒绝继续，不停服务、不写生产数据库、不创建系统账号/组。

TLS 和独立 SSH 私钥仅在校内生成和保留，返回 JSON 只包含公开证书、SSH 公钥及准备回执，尚不安装 SSH 授权或启动新连接。收到真实准备结果后，才能固定云端证书信任和候选配置。随后还需检查在途任务、备份与可回退激活、增加庭录所属路由和独立受限回环通道；不得扩大模型转发权限或重用 SimCourt 的端口。校园部署保留已有模型、权重、任务及校园入口，不因接入工具停止 GLM 或 SimCourt。

本机真实 Edge 已用两个合成账户验证免二次登录、超过一块的 WAV 上传、任务隔离、跨用户 404、退出及桌面/手机页面，代理到转发进程使用真实且正常验证的 TLS，测试关闭了 ASR 任务执行。尚需在实际校外 HTTPS 入口验证进度、播放拖动、原文编辑、Markdown 下载、取消与断线情形，同时回归原站和 SimCourt。现有校园 GPU 转写成功及本机传输验证，分别不能替代云端生产工作流或中文庭审质量验收。
