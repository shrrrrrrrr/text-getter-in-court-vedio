# 庭录视觉与交互基线

继承 AI + 法律项目已有工作台的奶油纸面 `#fbf6e8`、海军蓝 `#132a49`、青绿 `#087f80`、浅金提示与轻量像素几何。使用真实 ChillReunion Round v2.700 字体，静态 weight 500、禁止合成粗斜体，本地加载；许可见 `static/fonts/OFL.txt`，字体字节未修改，SHA256 为 `4f4e36dd0601c5fa325c6634649494767e9e7a0da8cc7b1fc9496ba1f7438288`。

阅读过的相关规范：[frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)的视觉与实现原则；项目既有工作台设计记录；[pbl-pixel-course](https://github.com/shrrrrrrrr/PBL-new-class/tree/main/skills/pbl-pixel-course) 的字体、公共色板、轻量几何和响应式规范。后者课程地图、人物精灵、教学权限不是本工具的功能要求，没有复制课程内容。

用户指定的法律站域名在本次开发环境中 DNS 解析失败，未声称读取到实时站点。已查看项目内已有工作台的真实截图，先沿用其中可验证的视觉系统；日后域名可访问时可进一步比对。

首页以导入为唯一主要行动，明确合成演示。工作区将原始现场/人物放左侧，时间序列逐字稿放右侧；桌面高度足够时两栏分别滚动，窄屏自然纵向排列。时间戳、文字、角色、证据、操作均为真实 DOM。未引入装饰性图片或远程字体。

输入中的原文、用户校对文本、导出内容不套用“去标点/去句号”等展示风格规则。大段原文保留空白与换行；搜索高亮只影响显示，不改存储值。状态同时用文字和颜色呈现，支持减少运动、键盘焦点、跳转内容与原生模态对话框。
