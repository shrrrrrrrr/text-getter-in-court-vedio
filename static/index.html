GETTING STARTED

把视频变成可核查的逐字稿

  1. 导入庭审视频

    选择视频文件、语言和音轨。本地模型需先安装依赖及权重，配置见仓库 README。云端识别需在服务端配置凭证，并在每次任务中明确同意。

  2. 逐句回听，核对人物

    点击时间回放；点击校对修改错字并记录已核听。人物卡可填写姓名、确认角色及依据。画面可辅助核对桌牌和自我介绍，本版未自动做人脸或口型识别。

  3. 重点检查重叠与听不清

    “重叠发言”筛选保留同时讲话的片段。实验性分离不保证中文庭审效果，分离声轨的跨段身份需手动归属，不能将其直接视为新人。

  4. 导出 Markdown

    逐字稿按开始时间排序，包含角色确认状态、起止时间和待核听项。JSON 保留原始文本与字词信息，修改记录可单独下载。

当前为本地单人开发版；完整角色识别、中文庭审准确率与多人重叠召回率尚需真实授权视频验收。未连接公网法律站。
